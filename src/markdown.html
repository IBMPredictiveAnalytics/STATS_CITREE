STATS CITREE Extension command

This procedure estimates classification and regression trees. In contrast to the CHAID, CART, and QUEST algorithms available in the SPSS TREES procedure, conditional inference trees use statistical significance test levels on means or categorical data with multiple testing corrections to find splits. These trees are less likely to overfit and are, therefore, more stable. That is, they generalize better to new data and will have fewer false branches.

Estimation and Prediction

DEPVARS specifies one or more dependent variables for the tree. Some functions only allow one variable. The variables' measurement levels determine the type of the tree.

INDVARS is the list of one or more variables to be used for splitting.

REGRVARS only applies to MOBLINEAR and MOBLOGISTIC model types. It specifies the list of regressors for the linear or logistic regression model.

IDVAR specifies an ID variable. It is required if making predictions. The variable can be used in merging the prediction dataset back with the input dataset with ADD FILES or similar commands. In some cases it might be necessary to adjust the variable type. The variable values must be unique.

ESTIMATE YES indicates that a tree should be estimated.

PREDICT YES indicates that a tree should be applied to a new dataset. The new dataset must have the same variables as were used for estimateion except that the IDVAR can be specified at estimation or prediction time. For predicting, the variables will be retrieved from the new input dataset automatically.

If neither ESTIMATE nor PREDICT is specified and a model has been estimated or reloaded from a file, the DISPLAY options can be used. This means, in particular, that plot parameters can be changed without the necessity of reestimating the tree even if the previous estimated tree was not saved.

FACTORMODE indicates whether categorical variable values or their value labels should be used. The labels are better for displaying the estimated tree and plots, but for prediction, values are better, since value labels are not data and are not necessarily unique. The two are equivalent if there are no value labels, but predictions cannot be made from actual labels.

MODELTYPE indicates the type of model to be estimated. CTREE estimates a standard conditional inference tree. MOBLINEAR indicates a linear regression tree and MOBLOGISTIC indicates a logistic regresion tree. For MOB types, the tree shows the regression estimates where they are significantly different across splits.

USEWORKSPACE indcates that the tree currently in the workspace be used for prediction. The most recently estimated or loaded model in the current session is availble for prediction use.

USEFILE specifies a file containing a model that was saved by SAVE MODELFILE. Using it would replace any model currently in the workspace.

If neither ESTIMATE nor PREDICT is specified but a model is in the workspace, its parameters will be displayed, and it can be used for displays.

MODELFILE specifies a file for saving the model for future use. It will be an R rdata file.

Prediction Parameters

DATASET specifies a dataset name for the predicted values. The dataset must not already be in use.

PREDTYPE specifies the type of predictions to be made.

  • RESPONSE is the predicted mean for a scale variable and the predicted category for a categorical variable.
  • QUANTILE specifies that quantiles be saved. It only applies to scale variables.
  • PREDPROB specifies the probability of the predicted class.
  • NODE specifies that the node number be saved. This can be very useful after merging the predicted dataset back to the input for examining the properties of the terminal nodes involvign other variables

QUANTILES specifies the list of quantiles to be saved if QUANTILE is chosen as the prediction type.

Displaying Results

TREES specifies a list of one or more trees to display. Trees are identified by their node number in the tree outline. Tree number 1 is the root, so the entire tree is displayed. Higher numbers display subtrees starting with that node. Entering 0 in the list causes any subsequent numbers to be ignored. By default, node 1, the entire tree, is displayed, but if it is large, displaying several subtrees may produce more readable output.

PLOTS specifies one or more plots of the tree to be displayed. The behavior is the same as for TREES.

CONFUSION specifies that a confusion table be displayed. It only applies to categorical dependent variables. The rows include all value labels for the dependent variable whether or not such values occur in the data.

MAINHEIGHT, MAINWIDTH, SUBHEIGHT, and SUBWIDTH display the sizes of the plots in inches. The MAIN dimensions apply to plot number 1, and the SUB values apply to any subplots. The procedure attempts to use an approximately appropriate size, but this cannot be determined exactly, so specifying a size allows the user to control the size as needed. Since the model is retained in the workspace by default, it is easy to revise the plots without reestimating the model.

FONTSIZE controlsl the point size of the font used in the plots. It defaults to 10 points.

PLOTBG specifies the background color for the plots. It can be any valid R color name. The default is lightblue.

INNERPLOTS specifies whether small plots are displayed at the interior nodes of the trees. This will likely require enlarging the plot size.

MATCHBG specifies whether the interior plot backgrounds match the general background of the plot or are white like the nodes themselves.

PLOTFILE specifies the file path for the plots. The node numbers will be added to the file names for the plot and have the extension appropriate for the chosen format.

PLOTFORMAT specifies the format for the plot files. The default is PNG, which is the format for the plots in the Viewer. SVG format may be the best choice if the software to be used for display supports that format, because it is resizable and editable.

TERMINALPLOTS controls whether small plots are displayed for each terminal node.

NODEPATHS controls whether a column showing the definition of each terminal node in SPSS syntax is include in the termstats table. The syntax shown may not be directly runnable due to differences in the way SPSS and R handle single and double quoted text.

SCTESTS specifies that a table showing all the significance test values be displayed as a table whether or not that splitpoint shows in the tree.

TERMSTATS specifies to display a table of statistics for the terminal nodes of the tree. It shows means for scale-level dependent variables and modes for categorical variables.

Options

These keywords control the statistical properties of the tree estimation. The options for CTREE models and MOB models are different.

MULTIWAY specifies whether multiway splits are enabled for nominal variables.

MISSINGVALUES specifies whether to include user missing values in the tree. System missing values are never included.

options for CTREE models

TESTSTAT: the type of the test statistic to be applied for variable selection

ALPHA: the significance level for variable selection

SPLITSTAT: the type of the test statistic to be applied for splitpoint selection

TESTTYPE: how to compute the distribution of the test statistic. The first three options refer to p-values as criterion, Teststatistic uses the raw statistic as criterion. Bonferroni and Univariate relate to p-values from the asymptotic distribution (adjusted or unadjusted). Bonferroni-adjusted Monte-Carlo p-values are computed when both Bonferroni and MonteCarlo are given.

MINCRITERION: the value of the test statistic or 1 - p-value that must be exceeded in order to implement a split

MINSPLITSUM: minimum sum of weights in a node in order to be considered for splitting

MINTERMINAL:the minimum sum of weights in a terminal node

MINPROB: proportion of observations needed to establish a terminal node

MAXSURROGATES: number of surrogate splits to evaluate

MAXDEPTH: maximum depth of the tree

CORES: number of CPU cores to use in the computation. Most modern computers provide multiple CPU cores. The default value is 1, but for large problems, increasing this value may speed up the procedure considerably. However, the availability and benefit may var with the operating system in use.

options for MOB

ALPHA: numeric significance level. A node is split when the possibly Bonferroni-corrected p value for any parameter stability test in that node falls below alpha

BONFERRONI: correct p values with Bonferroni correction

TRIM trimming in the parameter instability test for the numerical variables. If smaller than 1, it is interpreted as the fraction relative to the current node size

PRUNE AIC or BIC is used for post-pruning based on the corresponding information criteria. If omitted, no pruning is done

ORDINAL: the type of parameter instability test that should be employed for ordinal partitioning variables, i.e., ordinal categorical variables. If CHISQ, then the variable is treated as unordered and a chi-squared test is performed. If L2, then a maxLM-type test as for numeric variables is carried out but correcting for ties. This requires simulation of p-values and requires some computation time. For MAX, a weighted double maximum test is used that computes p-values

MINSIZE minimum number of observations in a node. the default is to use 10 times the number of parameters to be estimated divided by the number of responses per observation if that is greater than 1.

MAXDEPTH: the maximum depth of the tree

Vignette

VIGNETTELIST: Display selected articles. DIALOGHELP and SYNTAXHELP refer to the use of this procedure. The other keywords refer to articles covering the statistical foundations of the procedure along with information on the R code which is not needed for SPSS users.
